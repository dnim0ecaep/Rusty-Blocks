# Validation Codes

- `WFN001`: app name empty.
- `WFN002`: invalid package ID.
- `WFR001`: unknown root screen.
- `WFR002`: unknown component reference.
- `WFS001`: no windows defined.
- `WFS002`: no screens defined.
- `WFS003`: no event handlers warning.
- `WFT001`: unsupported target stack.
- `WFT002`: unknown component warning.
- `WFA001`: resource path empty.
- `WFI001`: AI task prompt empty.
