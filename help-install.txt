● Node.js isn't installed on this system, which is required to run the frontend. Here's
  what you need:

  1. Install Node.js (pick one):
  # via nvm (recommended)
  curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
  # then restart your shell, then:
  nvm install 22
  Or via your system package manager:
  sudo apt install nodejs npm

  2. Install pnpm (the workspace package manager):
  npm install -g pnpm@10

  3. Install frontend dependencies:
  cd /home/mdbeyhl/Code/Rustyblocks/apps/studio
  pnpm install

  4. Run the app:
  cd /home/mdbeyhl/Code/Rustyblocks/apps/studio/src-tauri
  cargo tauri dev

  Or from the workspace root:
  cd /home/mdbeyhl/Code/Rustyblocks
  pnpm dev

  That last command spins up the Vite dev server on port 5173 and launches the Tauri
  window against it. The tauri CLI is already present in node_modules/.bin/ and
  Rust/Cargo are already installed, so once Node is there you should be good to go.
